# Wedding Website Builder & Management Platform

A multi-tenant Next.js 14 web application and dynamic page builder platform for luxury wedding planning, guest RSVP, custom schedules, registries, interactive photo galleries, and admin management.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Backend & Auth**: Supabase (PostgreSQL, Row Level Security)
- **State & Forms**: React Hook Form, Zod, Lucide Icons, Framer Motion
